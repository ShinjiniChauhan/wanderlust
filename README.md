# 🌍 Wanderlust 

Wanderlust is an Airbnb-inspired full-stack web application where users can create, explore, and manage property listings along with reviews and ratings.

## ✨ Features
- User authentication (Login / Signup / Logout)
- Create, edit, and delete listings
- Upload images for Listings
- Add Reviews and Ratings
- View property details
- Responsive design

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript, EJS
- Backend: Node.js, Express
- Database: MongoDB
- Other: Cloudinary

## 🙌 Acknowledgement

This project is inspired by Airbnb and built for learning full-stack development.
